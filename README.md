📟 Smart Calculator

Smart Calculator is a modern, responsive, and interactive web-based calculator app featuring Standard and Scientific calculation modes with a sleek theme, history tracking, and customizable settings. Built with a focus on UI/UX, it delivers smooth functionality and a visually appealing experience.

🔧 Tech Stack

Frontend: HTML5, CSS3, JavaScript (ES6+)

Styling: Custom CSS with responsive design

Fonts: Google Fonts (Poppins, Montserrat)

Animations: CSS transitions & hover effects

Theme Support: Light & Dark mode with a glowing neon border effect



🎨 Styling & Theme

Default Dark Mode with glowing green border

Optional Light Mode with soft gradients

Smooth animations for button hover and mode transitions

Neon-glow effect for an engaging futuristic UI
